    Public Python API

    The source-checked contract is public-api.yml. The composition roots expose exactly two layers.

    Root Execution Faithful layer Journey layer
    IG(config) sync .operations .workflows
    AsyncIG(config) async .operations .workflows
    Namespace Purpose
    ig.operations.<resource> One typed IG provider operation.
    ig.workflows.<journey> A safe sequence composed from operations.

    Composition roots

    Composition roots for the operation- and workflow-oriented interface.

    Operations dataclass

    Synchronous namespaces that map directly to IG operations.

    Workflows dataclass

    Synchronous multi-operation journeys.

    AsyncOperations dataclass

    Asynchronous namespaces matching :class:Operations.

    AsyncWorkflows dataclass

    Asynchronous multi-operation journeys.

    IG

    Synchronous root exposing exactly operations and workflows.

    AsyncIG

    Asynchronous composition root for operation and workflow namespaces.

    Public failures

    Stable, provider-aware failures exposed by the public API.

    IGError

    Bases: RuntimeError

    Base error containing safe diagnostics for a failed IG request.

    AuthenticationError

    Bases: IGError

    Authentication or token-refresh failure.

    AuthorizationError

    Bases: IGError

    Credential does not grant access to the requested resource.

    RateLimitError

    Bases: IGError

    IG has rejected a request because a quota was exceeded.

    ProviderRejectionError

    Bases: IGError

    IG has rejected an otherwise well-formed request.

    ResourceNotFoundError

    Bases: IGError

    The requested IG resource does not exist or is inaccessible.

    TransportError

    Bases: IGError

    A network or timeout failure prevented a completed request.

    AmbiguousExecutionError

    Bases: IGError

    A mutation may have reached IG but its outcome cannot be known safely.

    DealConfirmationError

    Bases: IGError

    A mutation succeeded but its deal confirmation could not be retrieved.

    StreamingSubscriptionError

    Bases: IGError

    IG rejected a Lightstreamer subscription.

    StreamingDataLossError

    Bases: IGError

    A streaming subscription lost updates or exhausted its local buffer.
