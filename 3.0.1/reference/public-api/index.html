    Public API

    The package root, ig_trading_lib, is the supported import surface. Its __all__ exports are checked against the public API contract, where every parameter has a source-checked type and a concise description. The complete source reference below is generated by mkdocstrings and Griffe.

    IGClient and AsyncIGClient expose typed service namespaces and streaming clients. The REST API reference is the source-backed list of documented provider operations.

    Client construction

    Construct application clients from the package root. Obtain service namespaces from a client; do not construct them directly.

    IGClient(config: IGConfig, *, trading_permit: TradingPermit | None = None, http_client: httpx.Client | None = None)

    from ig_trading_lib import IGClient

    Parameter Type Description
    config IGConfig Immutable environment, credentials, timeout, retry, and account configuration.
    trading_permit TradingPermit | None Explicit acknowledgement required for guarded live mutations.
    http_client httpx.Client | None Optional caller-owned HTTP client.

    AsyncIGClient(config: IGConfig, *, trading_permit: TradingPermit | None = None, http_client: httpx.AsyncClient | None = None)

    from ig_trading_lib import AsyncIGClient

    Parameter Type Description
    config IGConfig Immutable environment, credentials, timeout, retry, and account configuration.
    trading_permit TradingPermit | None Explicit acknowledgement required for guarded live mutations.
    http_client httpx.AsyncClient | None Optional caller-owned HTTP client.
